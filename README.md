# Тест словарного запаса английского

Двухшаговый тест: отметьте слова, которые знаете, и получите оценку словарного запаса.

- Частоты слов: [SUBTLEX-US](https://github.com/words/subtlex-word-frequencies), словоформы объединены в леммы.
- Среди слов есть несуществующие — они корректируют результат.
- Весь сайт — один файл `index.html`, без сборки и зависимостей.
